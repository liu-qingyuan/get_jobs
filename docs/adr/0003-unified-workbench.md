# ADR 0003：统一管理，不合并简历文案或浏览器会话

## 决策

用户已授权统一工作台 V1（issue #4）。接续 ADR 0001/0002：在 JobsDB 副本加入 Spring/Next.js 管理入口，允许明确启动管理进程，但默认禁用招聘浏览器自动启动。原 `get_jobs/` 的文件、进程、数据库和浏览器不修改；现有国内安全修复仅复制源代码。旧 JobsDB CLI、数据目录、锁、审核和 UNKNOWN 防重合同保留。

个人资料由本地 Workbench Module 拥有，包含确认状态、来源、地区/网站作用域。旧资料仅显式预览导入，导入后仍未确认；更新联系方式不覆盖历史回执。密码、Cookie、验证码不导入通用资料。港区/国内、中/英文简历是四类独立档案，岗位版另存；批准后以附件 SHA256 和资料快照绑定任务，不就地覆盖。

官网不按公司实现驱动，也不自建浏览器 Agent。由操作人配置一个现有可信本机 CLI，参数数组直接启动，不拼接 shell。一次只启动一个执行任务（官网 AI、OfferToday 脚本和只读读取共享运行槽）；任务包和日志只保存在忽略的私有目录。任务凭据只用于该任务事件，提交占位必须收到 HTTP 成功响应后才可点击提交。执行器是受信任本机程序，不是操作系统沙箱；网页内容不得成为额外指令，禁止读取任务无关资料。仅向执行器交付已批准且适用的资料，而非全库。

工作台只记录执行器/用户报告及其证据，不声称直接观察了浏览器或雇主决策。退出码 0 不是成功；缺回执保留 UNKNOWN。平台申请仍使用原页面/CLI，不能把一个工作台岗位批准扩大成原有批次授权。JobsDB 账本只读展示并参与重复检查。

## 取舍

复用 Java 21、Spring、SQLite 与现有 Next.js，避免新框架。工作台数据单独保存在 `.workbench/`，与平台登录态隔离。企业状态先主动检查后登记，通知仅在工作台页面运行时尽力提供；不新增全天候调度、远程消息系统或自动项目执行。

## OfferToday 的单岗脚本接入

用户明确要求 OfferToday 使用已打开并登录的 Chrome。此渠道通过官方扩展的已授权标签页组复用现有浏览器，不新建登录 profile、不复制 Cookie，也不让它共享 Boss/JobsDB 的会话文件。平台网页知识由独立脚本 Adapter 拥有，工作台沿用材料冻结、单次执行及 UNKNOWN 合同，不另建浏览器 Agent。

OfferToday 只允许 HK 单岗 APPLICATION，可由 HTTP 在用户批准后显式启动附带脚本，这是单岗执行而非批次授权。官网仍走原外部命令；脚本读取当前已加载职位不创建或批准申请。首次消息与附件分开留证，只有匹配同岗、同次、同会话和冻结附件哈希的简历送达回执才完成。网页控件或自动招呼无法核实时停止，不借用官网 AI 猜测发送。

实站只读核对表明，职位卡片的 Chat/Apply 在打开编辑器前就调用状态变更接口，不能用作无副作用预检。适配器改用已登录页面的原生聊天状态入口，绑定详情返回的岗位与招聘者，再通过真实文字编辑器和简历选择器执行。原生 store/接口依赖被封装在 Adapter 内并固定已验证客户端版本；站点更新时阻塞，不尝试其他 minified 导出或猜测新流程。

消息清空、DOM 新行、transport packetsend 或本地 Loading 都不是送达证明。文字与简历必须分别对应新的、同一招聘者会话中的平台历史记录；简历还绑定审核文件的实际字节哈希与站内附件 ID。站内旧附件不能仅凭文件名或默认选中复用。新增附件不能删除/替换用户其他附件或改默认简历，已知容量/审核/字节校验阻塞应在联系前发现。

OfferToday 的 SUBMITTED 表示本次核准简历已获得上述平台持久化回执，不等同于招聘者已读、雇主决定或平台「求職紀錄」状态已更新。工作台只校验和保存受信执行器/人工提交的证据，不独立向招聘平台背书。

## AI 优先事实基线（issue #9，父 spec #7）

V1 的逐条录入保留作澄清/兜底，不再是唯一的事实核对入口。材料事实 Module 接受明确上传的文本、已登记来源 ID 和独立简历 ID；不接受服务器路径，不扫描目录，也不默认读取旧 JobsDB 或运行库。复用现有可信命令、私有任务包、有界超时和独占运行槽，不另造模型框架。材料分析使用单独的 `MATERIAL_REVIEW` 数据合同，无申请回调 token、账号或浏览器权限；可信执行器仍非 OS 沙箱。

模型只能提交候选与缺失说明。Module 按选定来源逐字核验依据、固定作用域，并展示重复/冲突；凭据和可识别指令行隔离，模型提供的确认标志及额外路径不生效。只有用户集中选择的可核对项成为确认事实；不把模型表述当作独立真实性证明。变化的来源保留版本，失去旧原文依据的当前事实退回待核实；原文依据未变时复用原确认，不要求每轮重填。事实修改/删除保留确认版本与来源，已批准任务的历史快照不回写。

简历仍是四类和岗位版的独立不可变记录，核准绑定实际附件 SHA256 与正文 SHA256。PDF/DOCX 无配套可读正文时明确缺证据，不猜测内容或自动核准。后续准备通过带适用地区、语言和可选网站的只读基线 Interface 获取当前已确认事实及匹配的核准简历；不获取未确认候选或其他地区/语言附件。范围授权、自动找岗、外发与项目执行不属于 #9，也不因确认基线而授权。

## 验证

临时 SQLite、fake 外部进程与 localhost 回调验证材料冻结、作用域、独占启动、提交占位和回执。浏览器页面测试只使用本机假资料；真实账号/官网实投必须单独授权验收。
