# 工作台回执上报 CLI

## 当前行为

读取显式指定的本机任务包，将事件以 JSON POST 上报到其中的回调地址。地址必须是无用户名、密码的本地 HTTP；不使用代理，也不携带任务凭据跟随重定向。请求使用任务 token，结果仅返回 `taskId` 和 `state`，不输出服务器返回的其他任务资料。

CLI 限定事件类型，可上报 `SUBMITTING`、`CONTACTED`、`CV_DELIVERED` 等既有事件，并可携带证据、动作及显式内容文件。读取、网络或结果格式错误时返回失败并要求停止，不自动重试。关联测试覆盖本地回调、两阶段事件、远端地址拒绝和重定向拒绝。

## 限制与剩余

本工具只负责上报及读取工作台回应，不执行浏览器动作，也不独立核验招聘站是否送达。调用方须先取得占位确认再执行不可逆动作；事件名称、退出码和本记录的版本指纹不能代替真实平台回执、简历字节绑定或业务测试。setup 只纳管本页声明的源码与测试，不代表其他工作台或渠道能力已纳管、已测试或已获生产资格。
