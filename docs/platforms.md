# 多平台能力总览

Get Jobs 是**本机求职工作台**，不是全平台自动投递服务。官网、OfferToday、Boss 和 JobsDB 共用候选、匹配与材料准备，但各渠道的真实读取、精确外发及回执能力不同。

::: warning 先分清四种状态
**链路接入**说明代码已连接；**隔离验证**使用 fake 来源、临时数据或 fixture；**实站读取**只证明授权范围内的真实只读样本；**外发资格**还须证明动作、精确材料与独立回执。前一项通过，不能代替后一项。

本页是仓库当前事实的说明，不是运行状态面板。免费 GitHub Pages 只发布静态文档，不运行工作台，不连接账号或本机资料库；发布文档也不会切换本机运行版本。
:::

## 统一工作台四渠道

| 渠道 | 链路接入 | 隔离验证 | 实站读取 | 外发资格与限制 |
| --- | --- | --- | --- | --- |
| 官网 / 外部 ATS（OFFICIAL） | 统一候选、匹配、备料与受控任务；需配置可信执行器，不内置任意 ATS 驱动 | 已有 fake 执行器、范围预算、冻结材料、占位与回执链路验证 | 来源和执行器需逐站验收，不保证任意官网可读、可投 | 仅在执行器具备能力、范围和材料授权有效时执行。唯一已授权官网试点证明正文与英文 PDF 送达，**正式申请仍为 UNKNOWN**，不是通用自动投递验收，也不得重投该目标 |
| OfferToday（OFFERTODAY，HK） | 独立 Python / Node.js Adapter；公开候选进入统一匹配、备料；已有单岗发送实现 | 公开详情、材料冻结、动作占位及独立历史回执等隔离验证通过，不等于实发 | **匿名公开完整 JD 读取已实站通过**；仅覆盖已核对的公开找岗路径，不等于账号或发送验收 | 新旧两版自动发送**未验收，保持关闭**；`dispatchProofByBuild` 的 `legacy` / `current` 仍为 `null`。缺少真实动作到同 ID 独立历史的证明及 CV 与核准字节的不可变绑定，不能因脚本或测试存在而启用 |
| Boss（BOSS，CN） | 已接统一候选、匹配、独立备料；只读 Adapter 复用本副本已显式登录且空闲的 Java 浏览器；CONTACT-only 受控 effect 已接入工作台 Runner | 候选、材料与拒绝不受控外发等隔离验证通过；新增 CONTACT fixture 覆盖首击前 claim、平台自动招呼回执与无 CV | **未完整验收**；连接、登录、访问限制、详情身份或全文不足均须显式例外 | **仅 CONTACT 已接入，尚未取得实站回执**。一次点击「立即沟通」只记录平台自己的「已向BOSS发送消息」，不写自拟正文、不打开编辑器、不发送 CV。2026-11-28 实站尝试在 claim 前安全停止：`browser-data` 仍被外部 Chrome 占用，应用启动持久上下文报 `Opening in existing browser session`；未 claim、未点击，未关闭用户浏览器。CV 仍须招聘者回复后的独立 SEND_CV |
| JobsDB（JOBSDB，HK） | 独立 Python / Scrapling 只读 CLI 已接统一候选、匹配、备料，保留独立会话、锁与账本 | 有界只读网络守卫、Service Worker 拒绝、材料准备与拒绝外发等隔离验证通过 | **未完整验收**；连接、验证墙、旧 Service Worker 状态或全文不足可阻断。早期样本不代替当前读取覆盖验收 | **受控外发尚未完整实现**；Profile 的适用资料、冻结附件实际字节与申请回执尚未精确桥接。不调用旧 `apply` / `batch`，不借官网通道绕过；原人工 CLI 保持独立语义 |

### 共同边界

- **确认事实不等于授权外发**：资料有来源和版本，地区 × 语言的简历独立维护；只有适用且明确选定的事实、核准附件才能用于本轮材料。AI 整理不是事实确认，开放式改写不自动获得核准。
- **范围许可不等于平台有能力**：范围固定来源、地区、材料、允许动作、累计预算与到期时间，默认仅准备。每个不可逆阶段还要重核并取得授权和原子 claim；未知结果不重放。
- **匹配和项目不制造经历**：匹配保留 JD / 材料依据；项目需独立资源授权与独立验收，另获许可后才追加有限的本地成果事实，不冒充任职、商业经验或年限，不回写旧简历与申请快照。
- **回执不等于雇主决定**：退出码 0、已联系、文件选中或正文送达都不是正式申请确认。OfferToday 首条联系仍保留 UNKNOWN，只有符合其冻结附件和独立平台历史合同的 CV 回执才可记 SUBMITTED；这也不代表已读或录用。

使用与合同细节：[工作台](/workbench) · [OfferToday](/offertoday-v1) · [JobsDB](/jobsdb) · [ADR 0003](/adr/0003-unified-workbench)。平台限制按 [文档父 Spec #21](https://github.com/liu-qingyuan/get_jobs/issues/21) 的已确认验收边界核对；本次文档交付不新增任何平台验收。
