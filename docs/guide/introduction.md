## 项目概述

**Get Jobs (工作无忧)** 是一个专为打工人打造的现代化开源全平台自动化求职脚本与管理系统。基于 **Spring Boot + Next.js + Playwright** 技术栈构建，通过结合 AI 大模型的能力，帮助求职者从繁重、重复的海投劳动中解放出来。

```
┌──────────────────────────────────────────┐
│ 前端层（Front） - Next.js, port=6866     │
│  - 任务创建、投递监控、配置管理界面      │
└──────────────────────────────────────────┘
                 │ HTTP / SSE
                 ▼
┌──────────────────────────────────────────┐
│ 后端层（API） - Spring Boot 3.5, port=9527 │
│  - 任务调度、数据库访问、状态推送        │
│  - 整合 Worker 模块执行自动化逻辑        │
│  - 提供 REST / SSE 接口供前端使用        │
└──────────────────────────────────────────┘
                 │ 内部模块调用
                 ▼
┌──────────────────────────────────────────┐
│ 执行层（Worker） - Java + Playwright     │
│  - 用户手动登录、岗位抓取、审核后执行      │
│  - 每个平台封装为独立模块（boss、51等） │
│  - 提供 Runner 接口供 Spring 调度        │
└──────────────────────────────────────────┘
```

## 核心特性

- **🖥️ 现代化图形界面**：提供直观易用的 Web 控制面板，配置关键词、筛选条件与投递日志一目了然。
- **🤖 AI 智能打招呼**：接入兼容 OpenAI 接口协议的大模型，目前仅限 Boss直聘，根据你的个人简历信息和 HR 发布的岗位 JD 动态撰写定制化高情商打招呼语。
- **📷 图片简历管理**：可上传供本地存储和预览，不写入资源目录或 JAR；本版禁止未经独立审核的自动图片发送。
- **🛡️ 智能过滤与黑名单**：自动跳过 **不活跃 HR**、**猎头/中介岗位**，支持自定义薪资区间；沟通不适的企业自动加入 SQLite 黑名单，避免重复投递。
- **📱 页面内状态与可选通知**：工作台只在页面运行期间更新状态，用户许可后尽力提供桌面提醒，不承诺每日统计、手机或全天候推送。旧平台 Webhook 的真实送达尚未验收，详见 [AI 与通知](/guide/ai-and-push)。
- **🔄 超长免登录状态**：支持持久化 Cookie 存储，大部分平台每周仅需扫码一次。

## 支持的求职平台

| 招聘平台 | 自动化状态 | 维护说明 | 推荐度 |
| :--- | :---: | :--- | :---: |
| **Boss直聘** | 待授权线上验收 | 官方更新与本地单岗门禁已合入并做模拟验证；不保证当前站点、额度或图片发送可用 | 先验证 |
| **猎聘** | 待授权线上验收 | 改版代码已合入，不把代码存在或编译通过当作送达证明 | 先验证 |
| **智联招聘** | ⚪ 停止维护 | 需指定默认在线/附件简历，现存功能不保证可用 | ⭐⭐ |
| **前程无忧 (51job)** | ⚪ 停止维护 | 搜索与投递存在限制，现存功能不保证可用 | ⭐⭐ |
| **拉勾网** | ⚪ 暂停维护 | 使用人数较少，欢迎社区贡献 PR | ⭐ |

::: warning ⚠️ 平台投递建议
目前核心维护与推荐使用的平台为 **Boss直聘** 与 **猎聘**。建议在 PC 端使用本项目作为兜底和批量过滤工具，对于极度心仪的核心岗位，配合手机端深入沟通效果更佳。
:::
